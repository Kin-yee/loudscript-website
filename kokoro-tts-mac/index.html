LoudScript / Kokoro guide

Kokoro TTS on Mac without Python

LoudScript runs Kokoro as an in-app model download. You do not need Python, pip, or Terminal. Kokoro needs an Apple silicon Mac and speaks English and Mandarin in LoudScript.

By Ho Ye Lam · Updated November 14, 2026

How do I use Kokoro on a Mac without Python?

Install LoudScript, download Kokoro from its Models settings, and select Kokoro as the speech model. Speech then runs on your Mac.

  1. Install LoudScript. It is a free, notarized DMG from the download page.
  2. Open the Models settings. Open Settings and select the Models tab, or choose Manage Models… from the speech model menu in the playback bar (it shows the current model’s name).
  3. Click Download (320 MB) next to Kokoro. If Apple System is still your speech model, LoudScript switches to Kokoro when the download finishes.
  4. Choose a language and voice. Expand Model Details under Kokoro to pick English or Mandarin and a voice. Mandarin is a separate model pack, so download Kokoro again after you choose Mandarin. Each English voice other than Heart downloads its voice pack the first time you use it.
  5. Press Play. Kokoro reads typed or pasted text, selected text from other apps, screenshot OCR, and PDF pages.

What does Kokoro need on a Mac?

  • An Apple silicon Mac. On an Intel Mac, LoudScript shows “Requires an Apple silicon Mac.” and disables the download.
  • macOS 15.6 or later. This is LoudScript’s own requirement.
  • About 320 MB to download. LoudScript checks for the download size plus 512 MB of free space before it installs a model.
  • A network connection for each download. That covers the model, the separate Mandarin model pack, and each English voice pack the first time you use that voice. After that, Kokoro synthesizes speech on your Mac.

Kokoro carries a Beta label in LoudScript. You can remove the model from the Models tab at any time.

Which languages does Kokoro speak in LoudScript?

English and Mandarin. LoudScript includes all 28 English voices from Kokoro v1.0 and 100 Mandarin voices from Kokoro v1.1-zh.

For other languages, use Apple System voices, Supertonic, or PocketTTS. The table below lists each model’s languages.

How does Kokoro compare with PocketTTS, Supertonic, and Phonon?

All four are optional downloads that synthesize speech on your Mac. They differ in languages, size, maturity, and whether LoudScript can save their audio to a file.

Download sizes are what LoudScript estimates on each Download button. Kokoro and Phonon need Apple silicon. Supertonic and PocketTTS run on Intel and Apple silicon Macs.

  • Kokoro suits compact English or Mandarin speech on Apple silicon.
  • PocketTTS covers six European languages with expressive voices. It is the largest download.
  • Supertonic has the widest language list and is the only downloaded model that can export audio.
  • Phonon is the newest model, added in LoudScript 0.1.45. It is a compact English model that reads numbers, prices, links, and abbreviations naturally. Gradium built it on Kyutai’s Pocket TTS.

The offline voices guide also covers Apple System voices.

Can I save Kokoro speech as an audio file?

Not in LoudScript today. Export Audio works with Apple System voices and an installed Supertonic model. LoudScript hides the Export Audio button while Kokoro, PocketTTS, or Phonon is the speech model.

See how to save text to speech as an audio file on Mac for the steps.

Does Kokoro in LoudScript work offline?

Yes, once the model and the voice you use are downloaded. LoudScript runs Core ML conversions of Kokoro made by FluidInference, and synthesis happens on your Mac. You still need a network connection to download models, voices, and app updates.

Optional AI formatting is separate. When you turn it on, the text being formatted can go to an AI provider. The privacy policy states the exact boundary.

How else can I run Kokoro on a Mac?

Install the upstream Python package. Choose this route if you want every Kokoro language and voice, scripting, or batch audio files.

pip install kokoro soundfile
  • Kokoro uses espeak-ng for English words outside its dictionary and for some other languages. The README gives install steps for Linux and Windows. On a Mac, Homebrew packages it as espeak-ng.
  • Mandarin needs an extra package, misaki[zh].
  • On Apple silicon, the README suggests setting PYTORCH_ENABLE_MPS_FALLBACK=1 to use the GPU.
  • The model card’s example writes 24 kHz WAV files.

The Python route gives you more control. LoudScript gives you Kokoro in a native Mac app with no setup.
