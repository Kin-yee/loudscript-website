LoudScript / Audio file guide

Save text to speech as an audio file on Mac

macOS can already do this. The say command in Terminal writes speech to an audio file. LoudScript adds an Export Audio button that saves WAV files from Apple System voices and Supertonic.

By Ho Ye Lam · Updated November 14, 2026

How do I convert text to an audio file on Mac?

Save your text as a plain text file, open Terminal, and run say with an output file.

  1. Save the text as a plain text file. For example, save it as article.txt.
  2. Run say in Terminal. Run say -o speech.aiff -f article.txt. It reads article.txt with your system voice and writes speech.aiff.
  3. Check the file. Open speech.aiff, or run afinfo speech.aiff to see its format and duration.

The -o option writes audio to a file instead of the speakers. The -f option reads the text from a file. You can also put the text in quotes after the options.

Pass the text with -f or as an argument. If you run say -o and type lines into Terminal, the file only holds audio for the last line.

How do I save text to speech as a WAV or M4A file?

Add --data-format. The file extension picks the container, and the data format picks the encoding.

FileCommandResult
WAVsay -o speech.wav --data-format=LEI16 -f article.txt16-bit PCM WAV
M4A (AAC)say -o speech.m4a --data-format=aac -f article.txtCompressed AAC audio
AIFFsay -o speech.aiff -f article.txt16-bit PCM AIFF (AIFF-C)

A .wav file without --data-format fails with “Opening output file failed: fmt?”. A .m4a file without --data-format=aac holds uncompressed audio. say cannot write MP3. say -o speech.mp3 reports no error, but the file it writes cannot be played.

We ran each command on macOS 27.0.1 and checked the files with afinfo. With the default system voice, every file was mono at 22,050 Hz. The sample rate can differ for other voices.

Which say options change the voice and speed?

  • -v Samantha selects a voice by name. Run say -v '?' to list the voices installed on your Mac.
  • -r 180 sets the rate in words per minute.
  • --file-format='?' lists every file format say can write and the data formats each one accepts.
  • --progress shows a progress meter while say writes the file.
say -v Samantha -r 180 -o speech.wav --data-format=LEI16 -f article.txt

How do I export speech to a WAV file in LoudScript?

Select Apple System or Supertonic as the speech model, open the text in the main window, and click Export Audio. LoudScript asks where to save, then writes a WAV file.

  1. Open the text in the main window. Type or paste it, pick an item from reading history, or import PDF pages.
  2. Choose a voice that exports. Select Apple System or Supertonic from the speech model menu in the playback bar (it shows the current model’s name). Download Supertonic first in Settings, under Models.
  3. Click Export Audio. The button shows a tray with a down arrow, between the speed control and Copy Text.
  4. Choose a folder and a name. The save dialog suggests a filename. Click Export.
  5. Wait for the progress bar. You can cancel at any time. When the file is ready, LoudScript shows “Exported” with the file name and selects the file in Finder.

Which LoudScript voices can export audio?

Speech modelExport Audio
Apple SystemYes. LoudScript uses the Apple voice it picks for the text’s language.
SupertonicYes, after you download the model.
Kokoro, PocketTTS, PhononNo. LoudScript hides the Export Audio button while one of these is the speech model.

Exports use your current speed setting. The Kokoro guide compares the downloadable models.

What file does LoudScript create?

  • Format. WAV only, with uncompressed audio. Supertonic writes mono 32-bit float samples. Apple System exports keep the format of the Apple voice. With the default voice on our test Mac, that was mono 32-bit float at 22,050 Hz.
  • Filename. LoudScript suggests the PDF’s file name, then the source page title, then the first sentence of the text. It replaces / : \ ? % * | " < > with spaces and keeps up to 60 characters. If nothing is left, the name is “LoudScript Audio.wav”. You can rename the file in the save dialog.
  • Location. The folder you pick in the save dialog. You can create a new folder there.
  • Safe saving. LoudScript builds the audio in a private temporary folder and moves the finished file into place. A cancelled or failed export leaves no partial file.
  • Length. Export Audio turns off when the text is over the 100,000-character limit shown under the editor.

LoudScript does not export MP3. To get a smaller file, convert the WAV with the built-in afconvert tool:

afconvert -f m4af -d aac speech.wav speech.m4a

Should I use say or LoudScript?

  • Use say for scripts, batch jobs, AIFF or M4A output, or any installed system voice by name. It needs no download.
  • Use LoudScript to export text you already read in the app, such as PDF pages or reading history, with a suggested filename, Supertonic voices, and a progress bar.
